# Digitalquintino Wilkerkyojogos

Vitrine digital da DigitalQuintino com e-books, mockups, busca, filtros, páginas individuais, checkouts e compartilhamento social.

## Executar localmente

```bash
pnpm install
pnpm run dev
```

## Build

```bash
pnpm run build
```

O workflow em `.github/workflows/pages.yml` publica automaticamente `dist/public` no GitHub Pages a cada push na branch `main`.
